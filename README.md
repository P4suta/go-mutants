# Go-mutants

Mutation testing for Go modules.

## Installation

```sh
git clone https://github.com/P4suta/go-mutants.git
cd go-mutants
go install ./cmd/go-mutants
```

## Usage

```sh
cd path/to/your-module
go-mutants run
```
